Expected patterns across sessions:

- **Struggle (recurring):** multiplies only the first term in brackets (09-26, 10-03, 10-17).
- **Struggle (improving):** sign errors when moving terms across `=` (09-26 and 10-03, fixed by 10-17).
- **What works:** area-model drawings (10-17 onward) and "what would you try first?" prompts.
- **Habit:** skips substitution checks unless asked.
- **Strength:** one-step equations.
